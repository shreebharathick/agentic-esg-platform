# Agentic ESG: Autonomous ESG Reporting Platform

An intelligent, multi-agent platform designed to automate enterprise Environmental, Social, and Governance (ESG) data ingestion, real-time carbon accounting, and self-updating regulatory compliance auditing (GRI, CSRD, GHG Protocol).

## Features
- **Automated ERP Ingestion:** Extracts financial and operational data from enterprise systems and unstructured utility invoices.
- **Autonomous Agentic Workflows:** Coordinates specialized agents for Scope 1, 2, and 3 emissions tracking and dynamic regulatory compliance checks.
- **Real-Time Analytics:** Interactive dashboard for computing ESG scores and tracking carbon footprint metrics.
- **Self-Updating Compliance:** Adapts reporting frameworks automatically based on changing regulatory standards.

## Tech Stack
- **Python / Pydantic**
- **LangChain / CrewAI** (Agentic frameworks)
- **Streamlit** (Interactive Dashboard UI)
- **Pandas / NumPy** (Data processing)
